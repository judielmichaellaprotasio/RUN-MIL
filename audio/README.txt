RUN MIL! SOUNDS
===============
All sounds are built in (generated by the game). To use your own recordings:

  1. Put the file in
         visuals/audio/sfx/     for sound effects   (example: visuals/audio/sfx/coin.mp3)
         visuals/audio/music/   for music           (example: visuals/audio/music/park.mp3)
  2. Open  visuals/audio/sounds.js  and add one line for it, e.g.   coin: "mp3",
     (the file lists every sound name and the music tracks you can replace)
  3. Refresh the game with Ctrl+F5.

A listed sound replaces the built-in one. If a file is missing or cannot be played, the built-in
sound plays, so nothing ever goes silent by accident.

  * Format: mp3, ogg, wav or m4a. Short effects (under 2 seconds) work best for sound effects.
  * Loudness: add  vol  to the entry, e.g.  coin: { ext: "mp3", vol: 0.6 }
  * Music loops. To skip an intro use  start  (seconds), e.g.  park: { ext: "mp3", start: 8 }
  * The Settings sliders (Music / Sound Effects) still control the volume of your files.
  * Open  soundtest.html  to play every slot and see whether it uses your file or the built-in sound.
  * Only use sounds you have the rights to if you publish the game.

VICTORY SONG (old way, still works)
  visuals/audio/victory.mp3 (or .m4a / .ogg / .wav) plays on the victory screen if there is no
  "victory" line under music in sounds.js.
